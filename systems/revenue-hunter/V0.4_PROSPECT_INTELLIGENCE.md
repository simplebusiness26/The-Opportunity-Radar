# Revenue Hunter v0.4 — Prospect Intelligence

Revenue Hunter remains a system separate from Opportunity Radar. It has its own state, scoring, sales pipeline, learning history and D1 data. The only outward connection is the explicit read-only exchange endpoint.

## Free-first rule

Core Revenue Hunter must work without paid agents, paid lead databases, Google Places, Hunter or Stripe.

Current core stack:
- Cloudflare Worker
- Cloudflare D1
- Cloudflare Browser Run binding
- OpenStreetMap/Overpass discovery fallback
- Direct public website fetch/audit
- Deterministic scoring/demo generation

Optional free enrichment:
- Companies House public API via `COMPANIES_HOUSE_API_KEY`

Held-back optional integrations:
- Google Places
- Hunter.io
- Stripe
- paid AI/design agents

## v0.4 capabilities

### Company identity graph
Merges public business name, website/domain, phone, postcode, Companies House match and brand signals into one confidence score.

### Companies House
When a free API key is connected, Revenue Hunter searches Companies House, matches candidates, records company number/status/type/SIC/address and retrieves a small active-officer list. It does not block the hunt when no key exists.

### Brand and image collection
Extracts from the company's own public website:
- logo
- favicon
- Open Graph/social image
- hero image
- small gallery candidate set

Assets are stored as source URLs/metadata in D1. Images are used for private prospect research and demos only.

### Visual evidence
`/visual/:prospectId?device=mobile|desktop` creates a live screenshot through Browser Run. Evidence and dossier pages show visual current-site context instead of raw JSON.

### Deep site audit
Uses cheap direct HTTP inspection first and audits up to four high-value pages when discoverable. Checks include quote/booking/contact/CTA/form signals, page failures and HTTPS. Browser Run is held for sites where rendered inspection adds value.

### Contact intelligence
Extracts phone numbers, emails, social links and contact-page hints from audited public pages. Paid contact enrichment is not required.

### Opportunity library
Maps findings into commercially sellable work such as quote funnels, booking flows, contact recovery, mobile rebuilds, website repairs and new conversion sites. Each entry contains deterministic delivery effort, price anchor and margin characteristics.

### Commercial economics
Each prospect can carry:
- score
- primary problem
- recommended solution
- indicative offer
- estimated delivery effort
- indicative delivery cost/margin
- identity confidence

### Dossier
Every prospect now has a full dossier combining company identity, contacts, images, screenshot, audit, opportunity economics and sales state.

### Better demos
Demo pages use collected brand assets, public business information and the selected opportunity. They do not fabricate testimonials, ratings, certifications or claims.

### Free-tier cost governor
Default per run:
- up to 20 prospects
- up to 8 deep audits
- up to 6 Browser Run actions
- up to 4 pages per deep audit
- 72-hour cache default

All values can be adjusted with Wrangler vars.

### Caching/reliability
Discovery, intelligence and Companies House matches are cached. Existing Overpass/Browser retry logic remains. Prospects are saved incrementally, so partial runs do not lose completed work.

### Sales workspace
Human-controlled stages:
`new -> saved -> draft_ready -> contacted -> replied -> interested -> proposal -> won/lost -> paid`

Dossiers can record next action and notes. Revenue Hunter does not autonomously send cold outreach.

### Learning loop
Recorded outcomes feed sector and opportunity summaries so Revenue Hunter can compare theoretical scores with real wins and paid revenue.

## One free connection still available

To activate UK company verification, add a Cloudflare secret named:

`COMPANIES_HOUSE_API_KEY`

Revenue Hunter remains fully operational without it.

## Paid features deliberately held back

Do not make these core requirements:
- `GOOGLE_PLACES_API_KEY`
- `HUNTER_API_KEY`
- `STRIPE_SECRET_KEY`
- premium design/LLM agents

They can be added later only after Revenue Hunter has generated revenue that justifies them.
